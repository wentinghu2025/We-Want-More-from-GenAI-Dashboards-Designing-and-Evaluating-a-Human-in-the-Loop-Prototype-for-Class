## What this repository is

[`interactive-demo/index.html`](interactive-demo/index.html) is a self-contained interactive replica of the "Face-to-Face DiscussionLens" dashboard mockup. The original mockup was generated with Base44 from the system prompt archived on OSF. Base44 outputs have no stable address, and the same prompt may not regenerate an identical interface. This replica, reconstructed from the archived system prompt and screenshots, keeps the design artefact in a stable, version-controlled place.

It preserves the Student and Teacher views as specified. It is a design illustration only, not an implemented or empirically evaluated system.

**Note:** clicking `index.html` in the file list shows its source code. To open the running page, use the live demo link above.

### Design-analysis overlay

A toggle ("Show Design Analysis", top right) shows which of the six design requirements and five architectural components each interface element is intended to realise, following Section 6.5.1 of the dissertation. It is off by default.
