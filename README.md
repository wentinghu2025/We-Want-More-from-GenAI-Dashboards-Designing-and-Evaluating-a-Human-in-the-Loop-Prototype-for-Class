## What this repository is

[`interactive-demo/index.html`](interactive-demo/index.html) is a **permanently-hosted, self-contained replica** of the "Face-to-Face DiscussionLens" dashboard mockup, originally generated via Base44 from the system prompt archived on OSF. Base44-generated prototypes are not permanently addressable — the same prompt can regenerate a visually different result, and there is no stable link to the original session. This file exists to give the design a **stable, re-openable, version-controlled home** independent of that tool.

The content and interactions (Student View / Teacher View, CPS Challenges accordion, CPS Skills table, Suggestions with star rating, AI Chatbot panel, etc.) are preserved exactly as specified in the original system prompt. **This is a design illustration, not an implemented or empirically evaluated system** — the same positioning maintained throughout the dissertation chapter that references it.

### Design-analysis overlay

The file includes an optional, toggleable annotation layer ("Show Design Analysis" button, top right). When enabled, small badges next to key interface elements reveal which of the dissertation's six epistemic design requirements and five architectural components that element is intended to realise, in the terms established in Section 6.5.1. The overlay is off by default; the page renders as a plain replica of the original mockup unless toggled on.

## Status of this repository

This repository is currently **private**. The dissertation chapter that references this material is still under revision. Once the dissertation reaches a stage appropriate for public sharing, this repository can be made public and GitHub Pages enabled to give the demo a live, clickable URL (the same pattern used for the author's other conference-poster repositories).

## Viewing the demo now, while the repository is private

Since GitHub Pages requires a public repository on the free tier, there is currently no live link. To view the demo:

1. Download [`interactive-demo/index.html`](interactive-demo/index.html) (or clone the repository)
2. Open the downloaded file directly in any browser — no server or installation needed
